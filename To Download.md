# To Download Data

To download info for each paper, run the following command, filling in the Pubmed ID as appropriate:

```
curl "https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esummary.fcgi?db=pubmed&id={Pubmed ID}" > info.xml
```
